## Vorbereiten der Arbeit mit Python

- Dieser PC - Verzeichnis mit eigenem Namen - dort in Verzeichnis 'Informatik' anlegen.
- Mit dem Explorer auf das Verzeichnis gehen und eine Verknüpfung auf den Desktop erstellen (Senden an Desktop)
- Auf dem Desktop die Verknüpfung so positionieren, dass sie leicht gefunden wird.
- Mit dem Explorer die Verknüpfung öffnen und die Zeile, in der der Pfad steht, überschreiben mit: cmd. Dann öffnet sich die das Windows CMD-Fenster in dem Informatik-Ordner.
- Dort eingeben: code .     (Den Punkt miteingeben) - es öffnet sich VSCode mit dem Informatik-Ordner als Basis. 
- File - Save Workspace AS - Desktop auswählen, den Namen Informatik.code-workspace lassen, Save.
Auf dem Desktop sollte jetzt auch eine Verknüpfung zu dem Informatik.code-workspace zu finden sein.
- Die Verknüpfung mit dem workspace ausprobieren, Terminal, jupyter lab


- Win-D (alle Fenster minimmieren), Win-E (Explorer) Win-Pfeil nach rechts, mit Klick auf den link auf dem Desktop den Explorer öffnen,  rechtsClick auf den Downloads-Ordner: in neuem Fenster öffnen, Win-Pfeil nach links, das downgeloadede File in den Informatik-Ordner ziehen.
